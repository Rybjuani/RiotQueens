# Roadmap

- Fase 0 — investigación: benchmarks, proveedores, costos, privacidad y pruebas de integridad.
- Fase 1 — prototipo personal: anfitriona, una compañera, memoria, router, validador, biblioteca y dos herramientas.
- Fase 2 — MVP cerrado: auth, créditos, notificaciones, 500–1.000 assets, cinco herramientas, métricas y 20 invitados.
- Fase 3 — beta: suscripciones, CDN, moderación, soporte y proveedores estables.
- Fase 4 — plataforma: múltiples personajes, marketplace, API, herramientas externas y app móvil.
