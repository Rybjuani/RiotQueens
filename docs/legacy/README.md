# Archivo histórico

Este directorio conserva documentación anterior para recuperar decisiones útiles, procedencia y contexto perdido.

Su contenido:

- no es canon vigente;
- no puede contradecir los dos landings ni [`SPECT.md`](../../SPECT.md);
- no autoriza cambios de producto, lenguaje o arquitectura;
- puede contener nombres, supuestos, enlaces y estados ya obsoletos.

## Companion Studio

- [`companion-studio/root/`](companion-studio/root/): archivos que estaban en la raíz del repo anterior.
- [`companion-studio/docs/`](companion-studio/docs/): arquitectura, contratos, handoffs, roadmap, visión y ADR históricos.

Los documentos se preservan como estaban siempre que sea posible. Las correcciones vigentes se escriben fuera de `legacy/`.
