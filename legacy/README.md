# Material histórico no canónico

Esta carpeta existe sólo para preservar material recuperable que fue retirado
del espacio operativo. No es una fuente de verdad, no define producto, roster,
tiers, capacidades, políticas, legalidad, arquitectura ni copy.

Un agente nuevo debe ignorar todo este árbol salvo que una tarea explícita
requiera recuperación forense o procedencia. La autoridad vigente está
únicamente en:

1. AGENTS.md
2. SPECT.md
3. README.md
4. RIOTQUEENS_CODEX_PHASE2_HANDOFF_ORGANIZADO.md
5. docs/DECISION_REGISTER.md
6. ADRs vigentes y código/tests

Los documentos aquí reunidos pueden contradecir esas fuentes por diseño.
Nunca deben reactivarse nombres, productos, tiers, prompts, proveedores o
decisiones históricas sólo porque aparezcan aquí.
